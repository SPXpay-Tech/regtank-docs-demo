TL;DR — recommendation: 🥇 Variant A (Scalar) for public docs, with the OpenAPI spec checked into the API repo. Scalar gives us ~90% of top-tier polish out of the box, free, self-hosted, and re-rendering just means pushing a new spec.yaml — no second source of truth. The hand-built SPA (Variant E) proves we can ship a Stripe-grade site if we ever need full design control, but that's months of work. Variant A ships today.

04 · The proposal

What I'd actually ship

Use Variant A (Scalar) as the public docs at docs.regtank.com — point it at spec/regtank-exchange.yaml checked into the API repo. Generate the spec from server-side annotations (springdoc-openapi on the Java side) so docs always match the deployed code. Keep x-codeSamples in YAML files alongside the spec, version-controlled.

The hand-built SPA stays in the repo as a reference — it proves we can deliver full design control if the brand team ever decides we need it.
